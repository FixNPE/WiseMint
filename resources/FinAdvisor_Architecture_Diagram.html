Supporting Layers — Knowledge, Data, Tools, Memory & LLMOps

📚 Knowledge Base RAG

  • Corpus: investor primers, tax & retirement guides, 30+ term glossary
  • Ingest: 800-char chunks / 120 overlap → BGE-small embeddings
  • Hybrid: BM25 + Chroma dense → RRF (k=60) → top-4 + citations

🌐 Live Market Data API

  • Alpha Vantage: quotes, fundamentals, news sentiment, sector, FX
  • Normalize: JSON → typed fields
  • Cache: SQLite, 30-min TTL, ~85% hit rate

🧮 Deterministic Tools Math

  • Projections: compound-interest FV, retirement
  • Schedules: savings-goal & debt amortization
  • Allocation: glide-path heuristic · portfolio risk metrics

👤 User Memory Persistent

  • Profile: age, income, risk, goals, holdings
  • Context: conversation history
  • Use: SQLite → injected as USER CONTEXT each turn

📈 Evaluation & LLMOps MLOps

  • Benchmarks: Financial PhraseBank, FiQA
  • LLM-as-judge: 5-dim rubric on advisor tasks
  • Ops: MLflow tracking · Docker · HF Spaces · CI
Overview

A guided tour of the FinAdvisor pipeline

Press Play to watch the request flow light up step by step, with spoken narration. Each box is broken down into its sub-components and the tools behind it. You can also click any block, or step through with the arrow keys.

Stack: Llama-3.3-70B (Groq) · ReAct agent · Hybrid RAG (BM25 + BGE-small + RRF, k=60) · ChromaDB · Alpha Vantage · SQLite · MLflow · Docker · Streamlit / Hugging Face Spaces. Domain adaptation is inference-side (prompt + RAG + tools) — deliberately not fine-tuning. Narration uses your browser's built-in voice; toggle 🔊 for silent mode.
